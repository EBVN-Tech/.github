# .github

Dépôt de configuration de l'organisation **EBVN Tech**.

Il contient les fichiers appliqués par défaut à tout dépôt de l'organisation
qui n'a pas sa propre version :

- `profile/README.md` — page d'accueil de l'organisation (github.com/EBVN-Tech)
- `CONTRIBUTING.md` — guide de contribution par défaut
- `CODE_OF_CONDUCT.md` — code de conduite
- `SECURITY.md` — politique de signalement des failles de sécurité
- `ISSUE_TEMPLATE/` — modèles de tickets
- `PULL_REQUEST_TEMPLATE.md` — modèle de pull request

Ce dépôt ne contient pas de code applicatif.
