# Contribuer

Merci de vouloir contribuer aux projets de l'association EBVN !

## Avant de commencer
- Vérifie qu'une issue n'existe pas déjà pour ce que tu veux faire
- Pour un changement important, ouvre d'abord une issue pour en discuter

## Proposer une modification
1. Fork le dépôt (ou crée une branche si tu es membre de l'organisation)
2. Crée une branche depuis `main` : `git checkout -b ma-fonctionnalite`
3. Fais tes modifications, avec des commits clairs
4. Ouvre une pull request vers `main` en décrivant le changement

## Revue
Chaque pull request doit être relue et approuvée avant merge sur `main`.

## Questions
Pour toute question, ouvre une issue ou contacte admin@ebvn.fr.
